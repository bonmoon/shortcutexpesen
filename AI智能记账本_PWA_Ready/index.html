本地数据

Local-first 已启用

主存储使用 IndexedDB，同时镜像到 localStorage。所有数据保存在当前设备浏览器中，不会由此页面上传服务器。

Shortcut URL 接口

Shortcut 最简单的方式是拼一个 URL，然后使用「打开 URL」。页面启动后会自动写入交易，再清理地址栏参数。

推荐直接传 payload=<DeepSeek JSON>；也兼容 action=add + date / type / amount / category / merchant / account / note 逐字段参数。

与 Numbers 文件对应

HTML 数据结构保留了原文件核心模块：

  • Dashboard / Mobile Dashboard
  • Transactions + Add Transaction
  • Category
  • Account
  • Budget
  • Monthly Summary
  • Settings

跨设备说明

Mac 浏览器与 iPhone Safari / 主屏幕 Web App 的本地数据库是各自独立的。这个版本不会把两台设备自动同步。

如果之后要真正双向同步，可以把同一 UI 接到 iCloud / Supabase / Cloudflare D1 等同步层；当前版本先保持无服务器、低成本。
